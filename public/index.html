Configuracion completa por Excel (nuevo)

Descarga esta plantilla, llenala con Proveedor, Codigo, Producto, Presentacion, Frecuencia (diario/semanal) y Tipo (habitual/adicional), y subela. La app identifica cada proveedor, actualiza todo, y para los proveedores nuevos te genera automaticamente usuario y contrasena, descargables en un Excel al final.

Usuarios de proveedores

Sincroniza usuarios y contraseñas desde el archivo de credenciales. Solo se modifican cuentas de proveedores. La cuenta administrador no se toca.

El archivo debe contener las columnas Proveedor, Usuario y Contraseña nueva. Si alguna fila no coincide con la base de datos, no se modifica ninguna contraseña.

Base PLU por proveedor

Carga el archivo maestro para actualizar qué productos suministra cada proveedor. La importación crea o actualiza relaciones proveedor–PLU y conserva el histórico de cotizaciones.

Admite columnas como: Proveedor, Código/PLU, Producto, Presentación, Frecuencia y Tipo. También admite las columnas corregidas del archivo revisado.

Frecuencia de cotizacion (diario / semanal)

Descarga la plantilla con todos tus proveedores y productos, marca en la columna "Frecuencia" si cada uno cotiza "diario" o "semanal", y súbela de vuelta para actualizar todo de una vez.
